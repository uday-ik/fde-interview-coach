# Guide: The Decomposition / Case Round

The signature FDE round. You're handed a vague, real-world enterprise problem.

**What great looks like**
1. **Clarify first** — data available, stakeholders, current workaround, what
   "success" means and how it's measured.
2. **Decompose** — turn the goal into a 4-week scope with a testable first
   deliverable, not a grand system.
3. **Name the riskiest assumption** — the one thing that, if wrong, sinks the
   project — and how you'd de-risk it (a pilot, an eval set, a fallback).
4. **Communicate the trade-offs** — say what you're *not* doing and why.

**Anti-patterns:** jumping to architecture before scoping; promising the moon;
no measurable success criteria.

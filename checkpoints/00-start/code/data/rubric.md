# FDE Interview Scoring Rubric

Each answer is scored **0–5** on four categories (max total **20**).

## Clarifying questions
Did the candidate surface unknowns before solving? Did they ask about data,
stakeholders, constraints, and success criteria instead of assuming?

## Decomposition
Did they break a vague problem into a scoped, sequenced plan with a clear,
testable first deliverable?

## Risk identification
Did they name the riskiest assumption and how they'd de-risk it (evals, a pilot,
a fallback)?

## Communication
Was the answer structured, concise, and pitched at the listener — could a
non-technical stakeholder follow it?

---

**Score guide per category:** 0 = absent · 1–2 = weak · 3 = solid · 4 = strong ·
5 = exceptional.
